Estimating \(\pi\)

Author

Apurva Nakade

Published

August 4, 2025

How can coin flips compute \(\pi\)? The answer is a quintessential example of the Monte Carlo principle:

ImportantThe Monte Carlo principle

Write the quantity we want as the expectation of a random variable, then estimate that expectation by an average of many samples.

This chapter works through three questions, with \(\pi\) as the running example.

  1. How do we write \(\pi\) as an expectation? We give two ways: points in a circle, and needles on a floor.
  2. How accurate is the resulting estimate, and how fast does it improve as we add samples?
  3. Are randomness-based methods faster or slower than non-random methods?

Along the way, we review the basics of probability that we’ll need throughout the course.

The circle estimator

Inscribe the unit circle in the square \([-1, 1] \times [-1, 1]\). A point chosen uniformly from the square lands inside the circle with probability equal to the ratio of the two areas, \[P(X^2 + Y^2 \leq 1) = \frac{\pi}{4}.\] So \(\pi\) is four times a probability, and a probability is the expectation of an indicator. Let \((X, Y)\) be uniformly distributed on the square and define \[ I(X, Y) = \mathbf{1}_{\{X^2 + Y^2 \leq 1\}} = \begin{cases} 1 & \text{if } X^2 + Y^2 \leq 1 \text{ (inside the circle)}, \\ 0 & \text{if } X^2 + Y^2 > 1 \text{ (outside the circle)}. \end{cases} \] Then \(I \sim \text{Bernoulli}(\pi/4)\) and \(\pi = 4\,\mathbb{E}[I]\). Replacing the expectation by a sample average gives our first estimator.

Definition 1 (The circle estimator) Given \(N\) independent uniform points \((X_1, Y_1), \ldots, (X_N, Y_N)\) in the square, write \(I_i = I(X_i, Y_i)\) and estimate \(\pi\) by \[\hat{\pi}_N = \frac{4}{N}\sum_{i=1}^{N} I_i = \frac{4 \cdot (\text{number of points inside the circle})}{N}.\]

By linearity of expectation, \(\mathbb{E}[\hat\pi_N] = 4\,\mathbb{E}[I] = \pi\) for every \(N\): the estimator is unbiased.

The app below draws \(N\) uniformly random points in the square and computes \(\hat\pi_N\).

Quantifying uncertainty

One way to quantify uncertainty in an unbiased estimator is via the standard error, \[\text{SE}(\hat\pi_N) = \sqrt{\text{Var}(\hat\pi_N)}.\]

  3. How does \(\text{SE}(\hat{\pi}_N)\) change with \(N\)?
  4. How many times more points does one more correct decimal place cost?
  5. Find the smallest \(N\) for which \(\text{SE}(\hat{\pi}_N) \le 0.001\).

Exercise 2 (Checking the rate) Compare the Standard error in the app at \(N = 100\) and at \(N = 10{,}000\). Does the ratio match your answer to Exercise 1 (c)?

Part (c) is the central fact of Monte Carlo:

ImportantThe \(N^{-1/2}\) rate

The standard error of an average of \(N\) i.i.d. samples with finite variance falls like \(N^{-1/2}\), whatever the problem. Only the constant depends on the problem.

You should find that each extra correct digit costs 100 times as many samples. Figure 1 repeats the experiment many times. The first chart shows that the estimates do converge to \(\pi\), and the second confirms that the error falls like \(N^{-1/2}\), as Exercise 1 predicts.

// "10⁻³" for 0.001: tick labels for a log axis whose ticks are powers of ten.
function piPowerOfTen(value) {
  const superscripts = {"-": "⁻", "0": "⁰", "1": "¹", "2": "²", "3": "³", "4": "⁴", "5": "⁵", "6": "⁶", "7": "⁷", "8": "⁸", "9": "⁹"}
  let exponent = ""
  for (const ch of String(Math.round(Math.log10(value)))) exponent += superscripts[ch]
  return `10${exponent}`
}

// Every power of ten from `lo` to `hi`.
function piDecades(lo, hi) {
  const ticks = []
  for (let k = Math.ceil(Math.log10(lo) - 1e-9); k <= Math.floor(Math.log10(hi) + 1e-9); k++) ticks.push(10 ** k)
  return ticks
}

// A log axis over [lo / pad, hi * pad] with a tick at each power of ten
// inside it, and none outside, where Plot would draw them past the frame.
// Only decades are ticked, so the x axis reads like the y axis instead of
// carrying every minor tick.
function piLogAxis(lo, hi, options, pad = 1) {
  const domain = [lo / pad, hi * pad]
  return {type: "log", domain, ticks: piDecades(domain[0], domain[1]), tickFormat: piPowerOfTen, ...options}
}

piFigureHeight = 240

// Running estimates: one line per run against N ≥ `from`, and a dashed line
// at π. Without a `yDomain`, the y axis fits every plotted estimate, so no

function piRunsFigure({counts, runs, title, xLabel, yDomain, from = 0, chartWidth = width}) {
  const rows = []
  let lo = Math.PI, hi = Math.PI
  for (let r = 0; r < runs.length; r++) {
    for (let i = 0; i < counts.length; i++) {
      if (counts[i] < from || runs[r][i] === null) continue
      rows.push({run: r, n: counts[i], estimate: runs[r][i]})
      lo = Math.min(lo, runs[r][i])
      hi = Math.max(hi, runs[r][i])
    }
  }
  let domain = yDomain
  if (!domain) {
    const range = VM.plotting.paddedRange([lo, hi], {relativePadding: 0.05, minPadding: 0})
    domain = [range.lo, range.hi]
  }
  const runColor = VM.plotting.alpha(chartColors.fn, 0.6)
  const chart = Plot.plot(VM.plotting.plotOptions({
    width: chartWidth, height: piFigureHeight, marginLeft: 46, marginBottom: 40,
    x: piLogAxis(Math.max(from, counts[0]), counts[counts.length - 1], {label: xLabel, labelAnchor: "center", tickFormat: "~s"}),
    y: {domain, label: "π estimate"},
    marks: [
      Plot.line(rows, {x: "n", y: "estimate", z: "run", stroke: runColor, strokeWidth: 1.5, clip: true}),
      Plot.ruleY([Math.PI], {stroke: chartColors.alt, strokeWidth: 2, strokeDasharray: "6,4"})
    ]
  }))
  return piFigure(chart, [
    {label: "Independent runs", stroke: runColor, strokeWidth: 1.5},
    {label: "π", stroke: chartColors.alt, strokeWidth: 2, strokeDasharray: "6,4"}
  ], title)
}

// Error decay: the RMS error over many runs, the band holding the middle 80%
// of runs, and a slope −1/2 reference raised above the band to compare with,
// over N ≥ `from`. Without a `yDomain`, the y axis fits the plotted values;
// with one, it stays put and anything outside is clipped.
function piErrorFigure({errors, title, xLabel, yDomain, from = 0, chartWidth = width}) {
  const last = errors[errors.length - 1]
  const rows = []
  for (const p of errors) {
    if (p.n >= from) rows.push({...p, reference: 2.5 * last.error * Math.sqrt(last.n / p.n)})
  }
  let lo = Infinity, hi = 0
  for (const row of rows) {
    lo = Math.min(lo, row.lo)
    hi = Math.max(hi, row.hi, row.reference)
  }
  const bandColor = VM.plotting.alpha(chartColors.fn, 0.15)
  const chart = Plot.plot(VM.plotting.plotOptions({
    width: chartWidth, height: piFigureHeight, marginLeft: 46, marginBottom: 40,
    x: piLogAxis(Math.max(from, errors[0].n), last.n, {label: xLabel, labelAnchor: "center", tickFormat: "~s"}),
    y: yDomain ? piLogAxis(yDomain[0], yDomain[1], {label: "|estimate − π|"}) : piLogAxis(lo, hi, {label: "|estimate − π|"}, 1.25),
    marks: [
      Plot.areaY(rows, {x: "n", y1: "lo", y2: "hi", fill: bandColor, clip: true}),
      Plot.line(rows, {x: "n", y: "reference", stroke: chartColors.ink, strokeWidth: 1.5, strokeDasharray: "6,4", clip: true}),
      Plot.line(rows, {x: "n", y: "error", stroke: chartColors.fn, strokeWidth: 2, clip: true}),
      Plot.dot(rows, {x: "n", y: "error", fill: chartColors.fn, r: 2, clip: true})
    ]
  }))
  return piFigure(chart, [
    {label: "RMS error", marks: [
      {mark: "line", stroke: chartColors.fn, strokeWidth: 2},
      {mark: "dot", fill: chartColors.fn, r: 2}
    ]},
    {label: "Middle 80% of runs", mark: "area", fill: bandColor},
    {label: "Slope −1/2", stroke: chartColors.ink, strokeWidth: 1.5, strokeDasharray: "6,4"}
  ], title)
}

Confidence intervals put a probability on the size of the error. By the central limit theorem, for large \(N\) the estimate \(\hat\pi_N\) is approximately normal, with mean \(\pi\) and standard deviation \(\text{SE}(\hat\pi_N)\).

Buffon’s needle

A second method to estimate \(\pi\) by random sampling goes back to Buffon in 1777. Take a floor made of parallel strips of wood, each of width \(t\), and drop a needle of length \(\ell \le t\) onto it at random. What is the probability that the needle lies across a line between two strips? The answer involves \(\pi\), so counting the needles that cross gives us a way to estimate \(\pi\).

The app below drops \(N\) needles of length \(\ell\) on lines spaced \(t = 1\) apart and colors the ones that cross a line. Leave the Shape switch on Needle for now; the noodle is the subject of Remark 1.

Exercise 5 (The crossing probability)  

  1. In the One needle drop panel, express \(h\) in terms of \(\ell\) and \(\theta\). Does your formula still hold when \(\theta > \pi/2\)?
  2. For which values of \(d\) does the needle cross a line? Where do you use \(\ell \le t\)?
  3. Sketch the region of the \((\theta, d)\) rectangle where the needle crosses a line, and use it to compute \(P(\text{cross})\).

You should find \[p = P(\text{cross}) = \frac{2\ell}{\pi t}.\] Now \(\pi\) sits inside a probability that we can estimate by dropping needles.

The estimator

If \(C\) of \(N\) needles cross a line, the fraction \(\hat p = C/N\) is an average of independent indicators, exactly like the circle estimator. So \(\hat p\) is unbiased for \(p\), and the analysis of Exercise 1 applies to it. Solving \(p = 2\ell/(\pi t)\) for \(\pi\) and substituting \(\hat p\) for \(p\) gives our second estimator.

Definition 2 (Buffon’s estimator) Drop \(N\) needles independently, and let \(C\) be the number that cross a line. Estimate \(\pi\) by \[\hat{\pi}_N = \frac{2 \ell N}{t\, C} = \frac{2\ell}{t}\cdot\frac{1}{\hat p}.\]

Bias

Exercise 6 (An undefined estimator) If \(C = 0\), the estimator is undefined: it divides by zero. Find \(P(C = 0)\) in terms of \(N\).

You should find that this probability shrinks geometrically in \(N\), so \(C = 0\) is negligible in practice. From here on, we assume that \(C \ge 1\).

The bias of an estimator \(\hat\pi_N\) is \[ \text{Bias}(\hat\pi_N) = \mathbb{E}[\hat\pi_N] - \pi. \] The circle estimator (Definition 1) is an average, so linearity gives it bias zero. Buffon’s estimator instead divides by a random count, and since \(x \mapsto 1/x\) is not linear, in general \[ \mathbb{E}[1/\hat p] \neq 1/\mathbb{E}[\hat p]. \] So linearity no longer computes \(\mathbb{E}[\hat\pi_N]\), and Buffon’s estimator is biased.

Exercise 7 (Bias)  

  1. Expand \(1/\hat p\) to second order about \(p\) and take expectations to approximate \(\mathbb{E}[\hat\pi_N]\) and the bias of \(\hat\pi_N\), in terms of \(p\) and \(N\).
  2. How fast does the bias shrink with \(N\)?
  3. The second-order term in (a) comes from the convexity of \(x \mapsto 1/x\). Use its sign to decide whether, for large \(N\), \(\hat\pi_N\) overestimates or underestimates \(\pi\). Can you interpret this directly?

Variance

For the variance, the linear term of the expansion is enough. This is the delta method: for a smooth function \(g\), \(g(\hat p) \approx g(p) + g'(p)(\hat p - p)\), so \[ \text{Var}(g(\hat p)) \approx g'(p)^2\, \text{Var}(\hat p). \]

Exercise 8 (Standard error)  

  1. Using the delta method approximate \(\text{Var}(\hat\pi_N)\) and \(\text{SE}(\hat\pi_N)\), in terms of \(p\) and \(N\).
  2. How does \(\text{SE}(\hat\pi_N)\) grow as \(\ell \to 0\)?
  3. Take the longest needle, \(\ell = t\). How many needles does it take to match the accuracy of \(N\) random points in the circle method (Exercise 1)?

Mean squared error

Because the estimator is biased, standard error is no longer a good measure of uncertainty. The mean squared error is the more appropriate measure in this case: \[ \text{MSE}(\hat\pi_N) = \mathbb{E}[(\hat\pi_N - \pi)^2]. \] In general, the MSE equals the variance plus the squared bias: \[ \text{MSE}(\hat\pi_N) = \text{Var}(\hat\pi_N) + \text{Bias}(\hat\pi_N)^2. \] For an unbiased estimator the MSE is just the variance.

Exercise 9 (Mean squared error)  

  1. Using your approximations from Exercise 7 and Exercise 8, find the ratio \(\text{Bias}(\hat\pi_N)/\text{SE}(\hat\pi_N)\).
  2. What happens to this ratio as \(N \to \infty\)? Which term dominates the MSE?
  3. Evaluate the bias and the standard error for \(\ell = t = 1\) and \(N = 100\).

You should find that even though the estimator is biased, the bias becomes negligible compared to the standard error as \(N\) grows. The MSE is then essentially the variance, so dividing by a random count changes the constant but not the \(O(N^{-1/2})\) rate of the error.

Randomness is slow

Both random methods converge at the Monte Carlo rate \(O(N^{-1/2})\) (Exercise 1, Exercise 9), so each extra decimal digit costs a hundred times more samples. That is far too slow to compute \(\pi\) in practice: the two methods are proofs of concept, not practical algorithms. Non-random methods do much better. We start with two that still count points in the disk, and end with a table of standard numerical methods.

The Gauss circle method

Gauss came up with a simple idea to measure the area of a circle: count the integer points \((x, y)\) with \(x^2 + y^2 \le r^2\), and call the count \(L(r)\). This approximates the disk’s area \(\pi r^2\), and \[ \hat\pi_r = \frac{L(r)}{r^2} \] estimates \(\pi\).

Halton points

Gauss’s method is a grid: its points come all at once, \((2r + 1)^2\) of them, and the one-loop trick of Exercise 10 relies on the shape of the disk. Can we keep the grid’s even coverage, but add points one at a time, as with random points?

The Halton sequence does this. Each new point roughly fills the gaps left by the earlier ones, so the first \(N\) points cover the square evenly for every \(N\). The points are not random at all: they are spread more evenly than random points would be. Such points are called quasi-random, and using them in place of random points is called quasi-Monte Carlo. The app below uses them in the circle estimator \(4 \cdot (\text{inside})/N\).

Summary

  • The Monte Carlo principle. Write a deterministic quantity as the expectation of a random variable, then estimate it by a sample average.
  • Two estimators of \(\pi\). The circle estimator is 4 times the fraction of uniform points of the square that land in the disk. Buffon’s estimator inverts the fraction of needles that cross a line, whose expectation is \(2\ell/(\pi t)\); by linearity, a needle of any shape gives the same mean (Barbier).
  • The Monte Carlo rate. An average of \(N\) i.i.d. samples with finite variance is unbiased, with standard error proportional to \(N^{-1/2}\). Each extra digit costs a hundred times more samples, whatever the problem. For large \(N\) the average is approximately normal, which gives confidence intervals.
  • Bias, variance and MSE. A nonlinear function of an average, like Buffon’s \(1/\hat p\), is biased. A Taylor expansion approximates the bias (second order) and the variance (first order, the delta method), and \(\text{MSE} = \text{Var} + \text{Bias}^2\). The bias shrinks like \(1/N\), faster than the standard error, so the rate stays \(N^{-1/2}\) and only the constant changes.
  • Randomness is slow. Points that cover the square more evenly than random ones do better: Halton points (quasi-Monte Carlo) and the Gauss circle method’s grid. Deterministic methods, such as quadrature and Newton’s method, are faster still.
